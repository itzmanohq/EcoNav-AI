# EcoNav AI – Intelligent Sustainable Navigation System

EcoNav AI is an AI-powered sustainable navigation system designed to help users choose eco-friendly and cost-efficient travel routes. Unlike traditional navigation systems that mainly focus on distance and travel time, EcoNav AI analyzes multiple factors such as vehicle type, fuel consumption, carbon emissions, and route efficiency to recommend smarter transportation decisions.

The system provides a comparison between normal routes and optimized eco-routes, helping users understand the impact of their travel choices on fuel expenses and the environment. It calculates estimated fuel costs, carbon footprint, travel distance, and time based on the selected vehicle type.

EcoNav AI integrates digital mapping technologies using Leaflet.js, OpenStreetMap, and routing APIs to visualize routes and provide real-time navigation insights. The platform supports different vehicle categories including petrol vehicles, diesel vehicles, bikes, and electric vehicles.

The main objective of EcoNav AI is to promote sustainable mobility by reducing unnecessary fuel consumption, lowering carbon emissions, and encouraging environmentally responsible travel decisions.

## Key Features

* Smart eco-friendly route recommendation
* Normal route vs Eco-route comparison
* Fuel cost estimation
* Carbon footprint calculation
* Multi-vehicle support
* EV-friendly navigation concept
* Interactive map-based route visualization
* Sustainable travel analysis

## Technologies Used

* HTML, CSS, JavaScript
* Leaflet.js for interactive maps
* OpenStreetMap for map data
* OSRM Routing API for route calculation

EcoNav AI combines navigation, environmental awareness, and intelligent analysis to create a next-generation green transportation solution.
